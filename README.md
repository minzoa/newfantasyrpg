# ASTRALIA · 아스트라리아: 별의 유산

브라우저에서 플레이하는 작은 완결형 3D 판타지 액션 RPG입니다. 별빛의 거점에서 출발해 에메랄드 숲과 고대 신전을 탐험하고, 별의 균열에서 수호자 아르켄을 해방합니다.

## 실행

Node.js 22.12 이상이 필요합니다. 프로젝트 폴더에서 실행하세요.

```powershell
npm install
npm run dev
```

터미널에 표시되는 주소(기본 `http://127.0.0.1:5173`)를 Chrome 또는 Edge에서 엽니다. WebGL 2와 키보드·마우스가 필요합니다. 전체 화면은 설정에서 선택할 수 있습니다.

```powershell
npm run build    # 타입 검사 및 dist/ 배포 파일 생성
npm run preview  # 빌드 결과 로컬 확인
npm test         # 게임 규칙 자동화 테스트
```

외부 서버·API 키·계정 없이 실행합니다. 배포 시 `dist/`를 정적 호스팅에 올릴 수 있습니다. 이번 프로젝트는 로컬 파일로 제공하며 외부 서비스에 배포하지 않았습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| W A S D | 카메라 기준 이동 |
| 마우스 휠 버튼 드래그 | 카메라 회전 |
| V | 마우스 잠금 / 해제, 잠금 중 마우스로 시점 제어 |
| 마우스 휠 | 시점 거리 조절 |
| 좌클릭 / 누르고 있기 | 3연격 또는 지팡이 별빛 탄환 |
| 우클릭 유지 | 정면 방어, 피격 시 마나 소비 |
| Space | 점프, 보스의 별빛 파동 넘기 |
| Shift | 회피 대시, 짧은 무적 시간 |
| Q | 별빛 폭발: 주변 범위 공격, 마나 18, 재사용 5.5초 |
| R | 별의 창: 관통 직선 공격, 레벨 3 해금, 마나 30, 재사용 11초 |
| 1 | 회복 물약 |
| E | 대화, 상자, 룬, 성소, 지역 이동 |
| I / J | 소지품·장비·특성 / 퀘스트 |
| Esc | 일시 정지 / 메뉴 닫기 |

메뉴와 대화 중에는 전투가 정지합니다. 창의 포커스를 잃거나 다른 탭으로 이동해도 일시 정지됩니다. 검은 가까운 전방 범위를 베고, 지팡이는 실제로 이동하는 탄환을 발사합니다. 방향·거리·공격 모션의 판정 시점이 적용됩니다.

## 여정

1. 기록자 엘리아에게 말을 걸어 별의 부름을 수락합니다.
2. 북쪽 아치에서 숲으로 이동합니다. 적 세 마리를 처치하고 숲의 별 파편을 얻습니다.
3. 신전에서 비문의 순서 **태양 → 별 → 달**로 석판을 깨우고 두 번째 파편을 얻습니다.
4. 균열의 수호자를 쓰러뜨리면 별의 핵이 복원되고 엔딩과 전설 보상을 얻습니다.

숲의 모든 적 처치, 세 보물함 발견, 네 지역 탐험은 선택 의뢰입니다. 퀘스트 화면에서 각각 한 번 보상을 받습니다. 성소는 주변에 적이 없을 때 회복과 저장을 제공합니다. 상점에서 물약과 장비를 구입하고, 소지품에서 장착·해제·정렬·폐기와 성장 특성 투자를 할 수 있습니다. 중요한 퀘스트 아이템과 장착 중인 장비는 폐기되지 않습니다.

보스는 검격·돌진·확산 파동을 사용하며, 체력이 절반 아래가 되면 낙성과 빠른 패턴이 추가됩니다. 붉은 예고 범위를 벗어나거나 방어·회피·점프로 대응하세요. 엔딩 이후 재도전은 첫 처치 보상을 중복 지급하지 않습니다.

## 저장

진행은 이 브라우저·주소의 `localStorage`에 자동 저장됩니다. 지역 이동, 보상 획득, 장비와 주요 행동, 주기적 자동 저장 및 수동 저장을 지원합니다. 이어하기는 마지막 지역 입구에서 재개합니다. 처치한 적, 획득한 상자와 파편, 장비, 성장, 퀘스트는 유지되지만 진행 중인 적의 체력은 초기화됩니다.

저장 키는 `astralia-save-v1`, 설정은 `astralia-settings-v1`입니다. 저장값은 버전·아이템 ID·장비 슬롯·지역·숫자 범위 등을 검증합니다. 새 게임은 기존 저장이 있을 때 확인합니다. 브라우저 데이터를 삭제하거나 다른 주소에서 실행하면 기존 저장을 읽을 수 없습니다. 클라우드 동기화는 없습니다.

## 구조와 기술 선택

- `game.ts`: 루프, 플레이어, 진행 흐름과 시스템 연결
- `combat.ts`, `enemies.ts`: 공간 판정, 투사체 충돌, 적 상태와 보스 패턴
- `domain.ts`: 능력치, 장비, 보상, 퀘스트, 저장 검증의 단일 규칙
- `world.ts`, `actors.ts`, `effects.ts`: 지역, 관절 캐릭터, 애니메이션과 전투 효과
- `input.ts`, `audio.ts`, `ui.ts`: 입력, 합성 음악·환경음·효과음, 실제 상태 기반 UI
- `contracts.ts`, `zones.ts`: 공통 타입과 콘텐츠 정의

Three.js로 직접 렌더링하고 TypeScript로 규칙을 검증합니다. 프레임 루프와 DOM UI를 분리해 React 없이 구성했습니다. 배경은 반복 식생 인스턴싱과 정적 메시 병합으로 처리하고, 적과 오브젝트는 지역 전환 시 정리합니다. 게임 속도는 프레임 시간이 기준이며 비활성 탭과 WebGL 컨텍스트 손실에 대응합니다. 그래픽 품질, 음악·환경음·효과음, 카메라 감도와 흔들림을 설정할 수 있습니다.

모든 캐릭터·환경·파티클·음악·효과음은 프로젝트 코드에서 생성하는 원본입니다. 외부 이미지·모델·음원 URL을 런타임에 사용하지 않습니다. 라이선스는 [ASSETS.md](ASSETS.md)를 참고하세요.

## 브라우저 검증

개발 서버를 켠 상태에서 별도 터미널로 실행합니다. 설치된 Chrome을 기본 사용하며 Edge는 환경 변수로 선택합니다.

```powershell
npm run test:browser
npm run test:resilience  # 사망·재시도, 점프, 설정, 데이터 손상, 작은 화면
# Edge를 사용할 경우:
$env:ASTRALIA_BROWSER = 'msedge'
npm run test:browser
```

테스트는 실제 WebGL 게임을 실행하고, 키보드 이동·메뉴·전투·퀘스트·상점·장비·저장 복원·보스와 엔딩을 검사합니다. 긴 이동은 개발 전용 위치 지정 도구로 생략하며, 처치와 보상은 실제 공격 모션·AI·충돌 로직으로 처리합니다. 별도의 사망 테스트는 체력이 1인 유효 저장 데이터를 준비한 뒤 실제 적 공격으로 사망을 유발합니다. 결과와 스크린샷은 `test-results/`에 생성됩니다. 테스트 도구는 개발 모드의 `?test=1`에서만 노출되며, 배포 빌드에서는 노출되지 않습니다.

배포 빌드 검증은 `npm run preview -- --port 5180 --strictPort` 실행 후 `node scripts/production-test.mjs`로 수행합니다. 상세 결과와 검증 범위는 [QA.md](QA.md)를 참고하세요.

## 범위

네 개의 작은 지역과 한 명의 최종 보스로 구성한 싱글 플레이 게임입니다. 상용 AAA 규모의 콘텐츠, 모션 캡처, 성우 음성, 복잡한 제작·동료 시스템, 모바일 터치 조작, 멀티플레이는 포함하지 않습니다. 절차적 메시와 관절 애니메이션을 사용하는 스타일라이즈드 아트입니다. 실제 성능은 GPU와 해상도에 따라 달라지며 낮음 설정으로 그림자와 픽셀 밀도를 줄일 수 있습니다.
